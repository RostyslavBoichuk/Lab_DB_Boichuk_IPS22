## ER-Модель

### Основні сутності

#### 1. ДИРЕКТОР (Director)
- **ПІБ** (full_name) - Повне імя
- **Дата призначення** (appointment_date) - Дата призначення на посаду

#### 2. ОРГАНІЗАЦІЯ (Organization)
- **Ідентифікатор** (id) - Унікальний код
- **Назва** (name) - Назва організації
- **Країна** (country) - Країна розташування
- **Рік заснування** (year_founded) - Рік заснування
- **Директор** (director_id) - Посилання на директора (FK)

#### 3. ЛАБОРАТОРІЯ (Laboratory)
- **ID** (id) - Первинний ключ
- **Назва** (name) - Назва лабораторії
- **Кількість співробітників** (num_employees) - Чисельність персоналу
- **Напрями діяльності** (activities) - Опис направлень роботи
- **Організація** (organization_id) - Посилання на організацію (FK)

#### 4. ЕКСПЕДИЦІЯ (Expedition)
- **Індекс** (id) - Унікальний код
- **Назва** (name) - Назва експедиції
- **Дата початку** (start_date) - Дата старту
- **Дата закінчення** (end_date) - Дата закінчення
- **Регіон** (region) - Географічний регіон
- **Директор** (director_id) - Посилання на директора (FK)

#### 5. РОЛЬ (Role)
- **ID** (id) - Первинний ключ
- **Назва** (name) - Назва посади/ролі
- **Опис** (description) - Опис ролі

#### 6. ДОСЛІДНИК (Researcher)
- **ID** (id) - Унікальний код
- **ПІБ** (full_name) - Повне імя
- **Спеціалізація** (specialization) - Область знань
- **Дата прийняття** (hire_date) - Дата прийняття на роботу
- **Роль** (role_id) - Посилання на роль (FK)
- **Лабораторія** (laboratory_id) - Посилання на лабораторію (FK)
- **Керівник** (supervisor_id) - Посилання на керівника (FK, self-reference)

#### 7. ОБЛАДНАННЯ (Equipment)
- **ID** (id) - Первинний ключ
- **Назва** (name) - Назва обладнання
- **Тип** (equipment_type) - Тип/категорія
- **Вартість** (cost) - Грошова вартість
- **Дата придбання** (purchase_date) - Дата придбання
- **Лабораторія** (laboratory_id) - Посилання на лабораторію (FK)

#### 8. КОНТРАКТ (Contract)
- **Індекс** (id) - Унікальний код
- **Назва** (title) - Назва контракту
- **Дата початку** (start_date) - Дата початку
- **Дата закінчення** (end_date) - Дата закінчення
- **Бюджет** (budget) - Фінансування
- **Дослідник** (researcher_id) - Посилання на дослідника (FK)
- **Організація** (organization_id) - Посилання на організацію (FK)

### Зв'язки між таблицями

```
ДИРЕКТОР (1) ──────┬──> ОРГАНІЗАЦІЯ (M)
                   └──> ЕКСПЕДИЦІЯ (M)

ОРГАНІЗАЦІЯ (1) ──┬──> ЛАБОРАТОРІЯ (M)
                  └──> КОНТРАКТ (M)

ЛАБОРАТОРІЯ (1) ──┬──> ДОСЛІДНИК (M)
                  └──> ОБЛАДНАННЯ (M)

ДОСЛІДНИК (1) ─────┬──> КОНТРАКТ (M)
                   └──> ЕКСПЕДИЦІЯ (M) (Many-to-Many)
                   └──> ДОСЛІДНИК (M) (Self-reference для керівництва)

РОЛЬ (1) ───────> ДОСЛІДНИК (M)
```

## Запити

### Прості параметризовані запити (5 шт.)

#### **Запит 1: Дослідники за спеціалізацією**
```sql
SELECT * FROM researchers 
WHERE specialization LIKE '%specialization%'
```
- **Параметр:** Спеціалізація (текстовий рядок)
- **Результат:** Список дослідників з вказаною спеціалізацією

#### **Запит 2: Обладнання вартістю вище від заданої**
```sql
SELECT e.* FROM equipment e
JOIN laboratories l ON e.laboratory_id = l.id
WHERE e.cost > :min_cost
```
- **Параметр:** Мінімальна вартість (число)
- **Результат:** Обладнання з вартістю вище за задану

#### **Запит 3: Експедиції у регіоні починаючи з року**
```sql
SELECT e.* FROM expeditions e
WHERE e.region = :region AND YEAR(e.start_date) >= :start_year
```
- **Параметри:** Регіон, стартовий рік
- **Результат:** Експедиції у вказаному регіоні за період

#### **Запит 4: Контракти з бюджетом та років дії**
```sql
SELECT c.*, r.full_name, o.name FROM contracts c
JOIN researchers r ON c.researcher_id = r.id
JOIN organizations o ON c.organization_id = o.id
WHERE c.budget > :min_budget AND YEAR(c.end_date) = :end_year
```
- **Параметри:** Мінімальний бюджет, рік закінчення
- **Результат:** Контракти за критеріями

#### **Запит 5: Лабораторії за кількістю співробітників**
```sql
SELECT l.*, o.name FROM laboratories l
JOIN organizations o ON l.organization_id = o.id
WHERE l.num_employees BETWEEN :min AND :max
```
- **Параметри:** Мінімальна та максимальна кількість
- **Результат:** Лабораторії у вказаному діапазоні персоналу

### Запити з множинними порівняннями (УСІ / ЛИШЕ)

#### **Запит 6: Дослідники з контрактами У ВСІХ організаціях**
```sql
SELECT r.* FROM researchers r
WHERE NOT EXISTS (
    SELECT 1 FROM organizations o
    WHERE NOT EXISTS (
        SELECT 1 FROM contracts c
        WHERE c.researcher_id = r.id AND c.organization_id = o.id
    )
)
```
- **Результат:** Дослідники, які мають контракти з КОЖНОЮ організацією системи

#### **Запит 7: Дослідники у всіх експедиціях**
```sql
SELECT r.* FROM researchers r
WHERE NOT EXISTS (
    SELECT 1 FROM expeditions e
    WHERE NOT EXISTS (
        SELECT 1 FROM expedition_researchers er
        WHERE er.expedition_id = e.id AND er.researcher_id = r.id
    )
)
```
- **Результат:** Дослідники, що беруть участь У ВСІХ експедиціях

#### **Запит 8: Експедиції з дослідниками ВСІХ спеціалізацій**
```sql
SELECT e.* FROM expeditions e
WHERE NOT EXISTS (
    SELECT 1 FROM (SELECT DISTINCT specialization FROM researchers) s
    WHERE NOT EXISTS (
        SELECT 1 FROM expedition_researchers er
        JOIN researchers r ON er.researcher_id = r.id
        WHERE er.expedition_id = e.id AND r.specialization = s.specialization
    )
)
```
- **Результат:** Експедиції, де представлені дослідники ВСІХ спеціалізацій

## Звіти

### Звіт 1: Експедиції та дослідники
- Показує кількість дослідників у кожній експедиції
- Розраховує середній стаж: **YEAR(start_date) - YEAR(hire_date)**
- Таблиця з датами проведення експедицій

### Звіт 2: Статистика лабораторій
- Кількість обладнання у кожній лабораторії
- Загальна вартість обладнання: **SUM(Equipment.cost)**
- Кількість дослідників у лабораторії
- Grupos за організаціями

### Звіт 3: Контракти дослідників
- Тривалість контракту у днях: **DATEDIFF(end_date, start_date)**
- Бюджет на день: **budget / DATEDIFF(end_date, start_date)**
- Звязок дослідника з його роллю
- Період контракту

### Звіт 4: Огляд організацій
- Кількість лабораторій: **COUNT(DISTINCT Laboratory.id)**
- Кількість експедицій: **COUNT(DISTINCT Expedition.id)**
- Загальний бюджет: **SUM(Contract.budget)**
- Призначений директор

### Асоціативні (Many-to-Many) таблиці

#### 1. **EXPEDITION_RESEARCHERS**
Зв'язок між експедиціями та дослідниками (Expedition ↔ Researcher)

```sql
CREATE TABLE expedition_researchers (
    expedition_id STRING(50) PRIMARY KEY,
    researcher_id STRING(50) PRIMARY KEY,
    FOREIGN KEY (expedition_id) REFERENCES expeditions(id),
    FOREIGN KEY (researcher_id) REFERENCES researchers(id)
);
```

**Призначення:** Дозволяє одному досліднику брати участь у кількох експедиціях, а експедиції мати команду з кількох дослідників.

---

#### 2. **FINANCES**
Зв'язок між організаціями та експедиціями (Organization ↔ Expedition)

```sql
CREATE TABLE finances (
    organization_id STRING(50) PRIMARY KEY,
    expedition_id STRING(50) PRIMARY KEY,
    FOREIGN KEY (organization_id) REFERENCES organizations(id),
    FOREIGN KEY (expedition_id) REFERENCES expeditions(id)
);
```

**Призначення:** Відслідковує, яка організація фінансує яку експедицію. Одна організація може фінансувати кілька експедицій, а експедицію можуть фінансувати кілька організацій.

---

#### 3. **EXPEDITION_EQUIPMENT**
Зв'язок між експедиціями та обладнанням (Expedition ↔ Equipment)

```sql
CREATE TABLE expedition_equipment (
    expedition_id STRING(50) PRIMARY KEY,
    equipment_id INTEGER PRIMARY KEY,
    FOREIGN KEY (expedition_id) REFERENCES expeditions(id),
    FOREIGN KEY (equipment_id) REFERENCES equipment(id)
);
```

**Призначення:** Визначає, яке обладнання задіяне в кожній експедиції.

---

#### 4. **RESEARCHER_EQUIPMENT**
Зв'язок між дослідниками та обладнанням (Researcher ↔ Equipment)

```sql
CREATE TABLE researcher_equipment (
    researcher_id STRING(50) PRIMARY KEY,
    equipment_id INTEGER PRIMARY KEY,
    FOREIGN KEY (researcher_id) REFERENCES researchers(id),
    FOREIGN KEY (equipment_id) REFERENCES equipment(id)
);
```

**Призначення:** Відслідковує, яким обладнанням користується кожен дослідник.

```python
class Director(db.Model):
    __tablename__ = 'directors'
    id = db.Column(db.Integer, primary_key=True)
    full_name = db.Column(db.String(255), nullable=False)
    appointment_date = db.Column(db.Date, nullable=False)
    
    organizations = db.relationship('Organization', backref='director', lazy=True)
    expeditions = db.relationship('Expedition', backref='director', lazy=True)
```

### **Запит 7: Дослідники, що беруть участь у всіх експедиціях**

#### Теоретична частина
**Тип запиту:** Складний запит з підзапитом та GROUP BY (квантифікація)  
**Множинність:** Нема параметрів → Мало записів (0:Few результат)  

**Опис:** Це складний запит, який знаходить дослідників, що беруть участь **у кожній** експедиції. Такі дослідники називаються "універсальними" або "omni-present". Це приклад запиту з квантифікацією "для всіх".

#### SQL еквівалент
```sql
SELECT r.* 
FROM researchers r
WHERE (
    SELECT COUNT(DISTINCT e.id) 
    FROM expeditions e
) = (
    SELECT COUNT(DISTINCT e.id)
    FROM expedition_researchers er
    JOIN expeditions e ON er.expedition_id = e.id
    WHERE er.researcher_id = r.id
)
ORDER BY r.full_name;
```

#### Реалізація в Python/SQLAlchemy
```python
def query_researchers_all_expeditions():
    """
    Запит 7: Дослідники, що беруть участь у всіх експедиціях
    """
    # 1. Отримуємо кількість всіх експедицій
    total_expeditions = db.session.query(func.count(Expedition.id)).scalar()
    
    # 2. Групуємо дослідників за кількістю експедицій
    researcher_expedition_counts = db.session.query(
        Researcher.id,
        func.count(Expedition.id).label('exp_count')
    ).join(Expedition, Researcher.expeditions).group_by(Researcher.id).all()
    
    # 3. Вибираємо дослідників, де count = total
    researcher_ids = [r[0] for r in researcher_expedition_counts if r[1] == total_expeditions]
    
    # 4. Повертаємо повну інформацію про дослідників
    return db.session.query(Researcher).filter(Researcher.id.in_(researcher_ids)).all()
```

#### Опис:
- **Параметрів:** Нема
- **GROUP BY:** Дослідник, підрахунок експедицій
- **HAVING:** Кількість експедицій = Загальна кількість експедицій
- **Результат:** Список дослідників (часто порожній, якщо ніхто не бере участь в усіх експедиціях)

#### Очікуваний результат
```
Запит: (без параметрів)
Результат:
Порожньо (якщо ніхто не бере участь в усіх експедиціях)
або
  - Петренко Іван (якщо бере участь в усіх 8 експедиціях)
  - Сідоров Петро (якщо бере участь в усіх 8 експедиціях)
```

**Пояснення:** Цей запит дуже корисний для знаходження "ключових гравців" у організації, які задіяні во всіх проектах.

### **Запит 8: Дослідники в одній лабораторії з однаковою спеціалізацією**

#### Теоретична частина
**Тип запиту:** Self-join з множинними умовами  
**Множинність:** Один параметр → Багато записів (1:N результат)  

**Опис:** Знаходження колег конкретного дослідника - тих, хто працює в тій же лабораторії та має таку ж спеціалізацію. Це демонструє self-reference та self-join операції.

#### SQL код
```sql
SELECT r2.* 
FROM researchers r1
INNER JOIN researchers r2 ON 
    r1.laboratory_id = r2.laboratory_id
    AND r1.specialization = r2.specialization
WHERE r1.id = '<target_researcher_id>'
    AND r2.id != r1.id
ORDER BY r2.full_name;
```

#### Реалізація в Python/SQLAlchemy
```python
def query_researchers_same_laboratory(target_researcher_id):
    """
    Запит 8: Дослідники в одній лабораторії з однаковою спеціалізацією
    """
    # 1. Отримуємо цільового дослідника
    target = db.session.query(Researcher).filter(
        Researcher.id == target_researcher_id
    ).first()
    
    if not target:
        return []
    
    # 2. Знаходимо всіх його колег
    return db.session.query(Researcher).filter(
        and_(
            Researcher.laboratory_id == target.laboratory_id,
            Researcher.specialization == target.specialization,
            Researcher.id != target.id
        )
    ).all()
```

#### Опис:
- **Параметр:** `target_researcher_id` (String)
- **Умови:** Та ж лабораторія AND та ж спеціалізація AND не я сам
- **Self-join:** Таблиця дослідників з'єднується сама з собою
- **Результат:** Список колег

#### Очікуваний результат
```
Запит: target_researcher_id = "RES001" (Петренко Іван з лаб. інформатики, програмування)
Результат:
  - Коваль Марія (Лаб. інформатики, програмування)
  - Сідоров Петро (Лаб. інформатики, програмування)
```

### **Звіт 2: Статистика лабораторій**

#### SQL еквівалент

```sql
    l.*,
    o.name as organization_name,

LEFT JOIN organizations o ON l.organization_id = o.id
LEFT JOIN equipment eq ON l.id = eq.laboratory_id
LEFT JOIN researchers r ON l.id = r.laboratory_id
GROUP BY l.id
ORDER BY total_equipment_cost DESC;
```

#### Реалізація в Python
```python
def get_report_lab_statistics():
    """ЗВІТ 2: Статистика лабораторій"""
    labs = db.session.query(Laboratory).all()
    results = []
    for lab in labs:
        equipment_count = Equipment.query.filter_by(laboratory_id=lab.id).count()
        total_cost = db.session.query(func.sum(Equipment.cost)).filter_by(
            laboratory_id=lab.id
```

### **Звіт 3: Контракти дослідників**

#### Опис

- Бюджет на день

#### SQL еквівалент
```sql
SELECT 
    r.full_name,
    ro.name as role_name,
    c.*,
    DATEDIFF(DAY, c.start_date, c.end_date) as duration_days,
    c.budget / DATEDIFF(DAY, c.start_date, c.end_date) as budget_per_day
FROM contracts c
LEFT JOIN researchers r ON c.researcher_id = r.id
LEFT JOIN roles ro ON r.role_id = ro.id
ORDER BY c.budget DESC;
```

#### Реалізація в Python
```python
def get_report_researcher_contracts():
    """ЗВІТ 3: Звіт про контракти дослідників"""
    results = []
    contracts = db.session.query(Contract).all()
    for contract in contracts:
        researcher = Researcher.query.get(contract.researcher_id)
        role = Role.query.get(researcher.role_id) if researcher else None
        duration_days = (contract.end_date - contract.start_date).days
        budget_per_day = contract.budget / duration_days if duration_days > 0 else 0
        results.append((researcher, role, contract, duration_days, budget_per_day))
    return results
```

```sql
SELECT 
    o.*,
    d.full_name as director_name,
    COUNT(DISTINCT l.id) as lab_count,
    COUNT(DISTINCT e.id) as expedition_count,
    COALESCE(SUM(c.budget), 0) as total_budget
FROM organizations o
LEFT JOIN directors d ON o.director_id = d.id
LEFT JOIN laboratories l ON o.id = l.organization_id
LEFT JOIN researchers r ON l.id = r.laboratory_id
LEFT JOIN contracts c ON r.id = c.researcher_id
LEFT JOIN expeditions e ON d.id = e.director_id
GROUP BY o.id
ORDER BY total_budget DESC;
```

#### Крок 2: Необхідно написати функцію звіту в queries.py

```python
def get_report_researcher_contract_summary():
    """
    ЗВІТ: Дослідники та їх контракти (побіжна інформація)
    
    Показує:
    - ПІБ дослідника
    - Лабораторія
    - Кількість контрактів
    - Загальна вартість контрактів
    """
    researchers = db.session.query(Researcher).all()
    results = []
    
    for researcher in researchers:
        contract_count = len(researcher.contracts)
        total_budget = db.session.query(func.sum(Contract.budget)).filter(
            Contract.researcher_id == researcher.id
        ).scalar() or 0
        
        lab = Laboratory.query.get(researcher.laboratory_id)
        
        results.append((researcher, lab, contract_count, total_budget))
    
    return sorted(results, key=lambda x: x[3], reverse=True)  # Сортувати по бюджету
```

### CRUD операції

#### Додавання нового запису
1. Необхідно перейти до розділу (наприклад, "Директори")
2. Необхідно натиснути кнопку "+ Додати директора"
3. Необхідно заповнити форму
4. Необхідно натиснути "Зберегти"

#### Редагування запису
1. Необхідно перейти до розділу
2. Необхідно знайти запис у списку
3. Необхідно натиснути "Редагувати" або на назву запису
4. Необхідно змінити дані
5. Необхідно натиснути "Зберегти"

#### Видалення запису
1. Необхідно перейти до розділу
2. Необхідно знайти запис у списку
3. Необхідно натиснути "Видалити"
4. Необхідно підтвердити видалення

#### Перегляд списку
1. Необхідно перейти до розділу
2. Побачите таблицю всіх записів
3. Необхідно клікнути на записи для редагування

---

### Виконання запитів

#### Запит 1: Дослідники за спеціалізацією
1. Необхідно перейти "Запити" → "Запит 1"
2. Необхідно ввести текст спеціалізації (наприклад: "програмування")
3. Необхідно натиснути "Пошук"
4. Побачите список дослідників

#### Запит 2: Обладнання дорого вартості
1. Необхідно перейти "Запити" → "Запит 2"
2. Необхідно ввести мінімальну вартість (наприклад: 50000)
3. Необхідно натиснути "Пошук"
4. Побачите список обладнання з лабораторіями

#### Запит 3: Експедиції по регіону та році
1. Необхідно перейти "Запити" → "Запит 3"
2. Необхідно ввести регіон (наприклад: "Африка")
3. Необхідно ввести рік початку (наприклад: 2020)
4. Необхідно натиснути "Пошук"

#### Запит 4: Контракти по бюджету та році
1. Необхідно перейти "Запити" → "Запит 4"
2. Необхідно ввести мінімальний бюджет
3. Необхідно ввести рік закінчення
4. Необхідно натиснути "Пошук"

#### Запит 5: Лабораторії по кількості співробітників
1. Необхідно перейти "Запити" → "Запит 5"
2. Необхідно ввести мінімум та максимум співробітників
3. Необхідно натиснути "Пошук"

#### Запити 6-8: Складні запити
Ці запити часто демонструють складну логіку SQL та можуть бути без параметрів або з однією змінною.
