## Встановлення

### Вимоги системи

- Python 3.7+
- pip (Python package manager)

### Кроки встановлення

1. **Перейти до папки проекту:**
   ```bash
   cd c:\Users\User\Downloads\DB\expeditions_db
   ```

2. **Встановити залежності:**
   ```bash
   pip install -r requirements.txt
   ```

3. **Ініціалізувати базу даних:**
   ```bash
   python run.py
   ```
   При першому запуску автоматично створюється база даних SQLite.

## ER-Модель

### Основні сутності

#### 1. ДИРЕКТОР (Director)
- **ПІБ** (full_name) - Повне імя
- **Дата призначення** (appointment_date) - Дата призначення на посаду

#### 2. ОРГАНІЗАЦІЯ (Organization)
- **Ідентифікатор** (id) - Унікальний код
- **Назва** (name) - Назва організації
- **Країна** (country) - Країна розташування
- **Рік заснування** (year_founded) - Рік заснування
- **Директор** (director_id) - Посилання на директора (FK)

#### 3. ЛАБОРАТОРІЯ (Laboratory)
- **ID** (id) - Первинний ключ
- **Назва** (name) - Назва лабораторії
- **Кількість співробітників** (num_employees) - Чисельність персоналу
- **Напрями діяльності** (activities) - Опис направлень роботи
- **Організація** (organization_id) - Посилання на організацію (FK)

#### 4. ЕКСПЕДИЦІЯ (Expedition)
- **Індекс** (id) - Унікальний код
- **Назва** (name) - Назва експедиції
- **Дата початку** (start_date) - Дата старту
- **Дата закінчення** (end_date) - Дата закінчення
- **Регіон** (region) - Географічний регіон
- **Директор** (director_id) - Посилання на директора (FK)

#### 5. РОЛЬ (Role)
- **ID** (id) - Первинний ключ
- **Назва** (name) - Назва посади/ролі
- **Опис** (description) - Опис ролі

#### 6. ДОСЛІДНИК (Researcher)
- **ID** (id) - Унікальний код
- **ПІБ** (full_name) - Повне імя
- **Спеціалізація** (specialization) - Область знань
- **Дата прийняття** (hire_date) - Дата прийняття на роботу
- **Роль** (role_id) - Посилання на роль (FK)
- **Лабораторія** (laboratory_id) - Посилання на лабораторію (FK)
- **Керівник** (supervisor_id) - Посилання на керівника (FK, self-reference)

#### 7. ОБЛАДНАННЯ (Equipment)
- **ID** (id) - Первинний ключ
- **Назва** (name) - Назва обладнання
- **Тип** (equipment_type) - Тип/категорія
- **Вартість** (cost) - Грошова вартість
- **Дата придбання** (purchase_date) - Дата придбання
- **Лабораторія** (laboratory_id) - Посилання на лабораторію (FK)

#### 8. КОНТРАКТ (Contract)
- **Індекс** (id) - Унікальний код
- **Назва** (title) - Назва контракту
- **Дата початку** (start_date) - Дата початку
- **Дата закінчення** (end_date) - Дата закінчення
- **Бюджет** (budget) - Фінансування
- **Дослідник** (researcher_id) - Посилання на дослідника (FK)
- **Організація** (organization_id) - Посилання на організацію (FK)

### Зв'язки між таблицями

```
ДИРЕКТОР (1) ──────┬──> ОРГАНІЗАЦІЯ (M)
                   └──> ЕКСПЕДИЦІЯ (M)

ОРГАНІЗАЦІЯ (1) ──┬──> ЛАБОРАТОРІЯ (M)
                  └──> КОНТРАКТ (M)

ЛАБОРАТОРІЯ (1) ──┬──> ДОСЛІДНИК (M)
                  └──> ОБЛАДНАННЯ (M)

ДОСЛІДНИК (1) ─────┬──> КОНТРАКТ (M)
                   └──> ЕКСПЕДИЦІЯ (M) (Many-to-Many)
                   └──> ДОСЛІДНИК (M) (Self-reference для керівництва)

РОЛЬ (1) ───────> ДОСЛІДНИК (M)
```

## Функціональність

### 1. Управління даними

Додаток надає можливість додавання, редагування та видалення записів для:

- **Директори** - Керівники організацій та експедицій
- **Організації** - Наукові установи та організації
- **Лабораторії** - Окремі лабораторії у складі організацій
- **Експедиції** - Польові дослідження та експедиції
- **Ролі** - Посади та ролі у системі
- **Дослідники** - Учасники досліджень з посиланнями на керівників
- **Обладнання** - Приладдя та обладнання лабораторій
- **Контракти** - Угоди та контракти для дослідницьких проектів

### 2. Форми введення

Всі форми мають:
- ✅ Валідацію даних на клієнті та сервері
- ✅ Випадаючі списки для вибору іноземних ключів
- ✅ Зручний інтерфейс з українськими назвами полів
- ✅ Кнопки "Зберегти" та "Скасувати"

### 3. Навігація

- Головна сторінка-меню з посиланнями на всі розділи
- Кнопка "Повернутися до меню" на кожній сторінці
- Навігаційна стрічка в верхній частині

## Запити

### Прості параметризовані запити (5 шт.)

#### **Запит 1: Дослідники за спеціалізацією**
```sql
SELECT * FROM researchers 
WHERE specialization LIKE '%specialization%'
```
- **Параметр:** Спеціалізація (текстовий рядок)
- **Результат:** Список дослідників з вказаною спеціалізацією

#### **Запит 2: Обладнання вартістю вище від заданої**
```sql
SELECT e.* FROM equipment e
JOIN laboratories l ON e.laboratory_id = l.id
WHERE e.cost > :min_cost
```
- **Параметр:** Мінімальна вартість (число)
- **Результат:** Обладнання з вартістю вище за задану

#### **Запит 3: Експедиції у регіоні починаючи з року**
```sql
SELECT e.* FROM expeditions e
WHERE e.region = :region AND YEAR(e.start_date) >= :start_year
```
- **Параметри:** Регіон, стартовий рік
- **Результат:** Експедиції у вказаному регіоні за період

#### **Запит 4: Контракти з бюджетом та років дії**
```sql
SELECT c.*, r.full_name, o.name FROM contracts c
JOIN researchers r ON c.researcher_id = r.id
JOIN organizations o ON c.organization_id = o.id
WHERE c.budget > :min_budget AND YEAR(c.end_date) = :end_year
```
- **Параметри:** Мінімальний бюджет, рік закінчення
- **Результат:** Контракти за критеріями

#### **Запит 5: Лабораторії за кількістю співробітників**
```sql
SELECT l.*, o.name FROM laboratories l
JOIN organizations o ON l.organization_id = o.id
WHERE l.num_employees BETWEEN :min AND :max
```
- **Параметри:** Мінімальна та максимальна кількість
- **Результат:** Лабораторії у вказаному діапазоні персоналу

### Запити з множинними порівняннями (2+ шт.)

#### **Запит 6: Дослідники з однаковою спеціалізацією**
```sql
SELECT r1.* FROM researchers r1
WHERE r1.specialization IN (
    SELECT r2.specialization FROM researchers r2 
    WHERE r2.specialization = :specialization
)
```
- **Результат:** Всі дослідники з однаковою спеціалізацією

#### **Запит 7: Дослідники у всіх експедиціях**
```sql
SELECT r.* FROM researchers r
WHERE NOT EXISTS (
    SELECT 1 FROM expeditions e
    WHERE NOT EXISTS (
        SELECT 1 FROM expedition_researchers er
        WHERE er.expedition_id = e.id AND er.researcher_id = r.id
    )
)
```
- **Результат:** Дослідники, що беруть участь у всіх експедиціях

#### **Запит 8: Колеги в одній лабораторії**
```sql
SELECT r.* FROM researchers r, researchers r_target
WHERE r.laboratory_id = r_target.laboratory_id
AND r.specialization = r_target.specialization
AND r.id != r_target.id
```
- **Результат:** Дослідники, що працюють разом в одній лабораторії

## Звіти

### Звіт 1: Експедиції та дослідники
- Показує кількість дослідників у кожній експедиції
- Розраховує середній стаж: **YEAR(start_date) - YEAR(hire_date)**
- Таблиця з датами проведення експедицій

### Звіт 2: Статистика лабораторій
- Кількість обладнання у кожній лабораторії
- Загальна вартість обладнання: **SUM(Equipment.cost)**
- Кількість дослідників у лабораторії
- Grupos за організаціями

### Звіт 3: Контракти дослідників
- Тривалість контракту у днях: **DATEDIFF(end_date, start_date)**
- Бюджет на день: **budget / DATEDIFF(end_date, start_date)**
- Звязок дослідника з його роллю
- Період контракту

### Звіт 4: Огляд організацій
- Кількість лабораторій: **COUNT(DISTINCT Laboratory.id)**
- Кількість експедицій: **COUNT(DISTINCT Expedition.id)**
- Загальний бюджет: **SUM(Contract.budget)**
- Призначений директор
