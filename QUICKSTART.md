# Швидкий старт

## Встановлення та запуск

### 1. Встановлення залежностей

```bash
cd c:\Users\User\Downloads\DB\expeditions_db
pip install -r requirements.txt
```

### 2. Запуск додатка

```bash
python run.py
```

Додаток запуститься на: **http://localhost:5000**

### 3. Використання системи

- На головній сторінці натисніть на один із розділів:
  - **Директори, Організації, Лабораторії** - управління базовими сутностями
  - **Експедиції, Ролі, Дослідники** - управління людськими ресурсами  
  - **Обладнання, Контракти** - управління ресурсами
  - **Запити** - виконання параметризованих запитів (8 запитів)
  - **Звіти** - перегляд аналітичних звітів (4 звіти)

## Структура папок

```
expeditions_db/
├── app.py                 # Головна Flask програма
├── models.py              # ORM моделі бази даних
├── forms.py               # Форми для введення даних
├── queries.py             # Запити та звіти
├── config.py              # Конфігурація
├── run.py                 # Точка входу
├── requirements.txt       # Залежності
├── expeditions.db         # SQLite база даних (створюється автоматично)
├── README.md              # Повна документація
├── LAB_REPORT.txt         # Звіт по лабораторній роботі
└── templates/             # HTML шаблони

```

## Головні функції

### ✅ Введення даних
- Форми для всіх таблиць
- Вибір іноземних ключів зі списків
- Валідація даних

### ✅ Запити (8 шт.)
1. Дослідники за спеціалізацією
2. Обладнання вартістю вище від заданої
3. Експедиції у регіоні
4. Контракти з бюджетом
5. Лабораторії за кількістю співробітників
6. Дослідники з однаковою спеціалізацією
7. Дослідники у всіх експедиціях
8. Колеги в одній лабораторії

### ✅ Звіти (4 шт.)
1. Експедиції та дослідники (з розрахунком стажу)
2. Статистика лабораторій (з сумою вартості обладнання)
3. Контракти дослідників (з розрахунком бюджету на день)
4. Огляд організацій (з сумою бюджетів)

## Технологічний стек

- **Backend:** Python 3.7+ + Flask
- **Database:** SQLAlchemy ORM + SQLite
- **Frontend:** HTML5 + CSS3 + Jinja2
- **Forms:** WTForms
