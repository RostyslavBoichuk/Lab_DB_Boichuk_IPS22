1. ТЕКСТОВИЙ ОПИС ПРЕДМЕТНОЇ ОБЛАСТІ
═══════════════════════════════════════════════════════════════════════════════

ПРЕДМЕТНА ОБЛАСТЬ: Система управління дослідницькими експедиціями

ОПИСАННЯ:
База даних призначена для управління дослідницькими експедиціями, організаціями,
лабораторіями, дослідниками, обладнанням та контрактами. Система підтримує:

1. ОРГАНІЗАЦІЙНА СТРУКТУРА
   - Кілька наукових організацій (інститути, університети, дослідницькі центри)
   - Кожна організація має свого директора
   - У складі організації знаходиться одна або більше лабораторій
   - Кожна лабораторія спеціалізується на певних напрямках діяльності

2. ЛЮДСЬКІ РЕСУРСИ
   - Дослідники працюють у лабораторіях
   - Кожен дослідник має посаду (роль) та спеціалізацію
   - Можливі відносини керівництва між дослідниками
   - Відповідність між дослідниками та експедиціями (М:М)

3. ЕКСПЕДИЦІЇ
   - Польові дослідницькі експедиції у різних регіонах
   - Під керівництвом директора
   - Містять групи дослідників
   - Мають дати початку та закінчення

4. РЕСУРСИ
   - Обладнання кожної лабораторії (приладдя, інструменти)
   - Облік вартості та дати придбання обладнання

5. КОНТРАКТИ
   - Угоди між дослідниками та організаціями
   - Включають бюджет та період виконання

ФУНКЦІОНАЛЬНІСТЬ:
- Додавання, редагування, видалення записів всіх типів
- Пошук дослідників за спеціалізацією та іншими критеріями
- Пошук обладнання за вартістю
- Пошук експедицій за регіоном та часом
- Аналітичні запити щодо структури організацій
- Звіти зі статистичною інформацією

ЗАПИТ 1: Дослідники за спеціалізацією
──────────────────────────────────────
Формулювання: Знайти всіх дослідників, спеціалізація яких містить вказане 
              слово або фразу.

SQL-код:
SELECT * FROM researchers 
WHERE specialization LIKE '%:specialization%'

Python SQLAlchemy:
def query_researchers_by_specialization(specialization):
    return db.session.query(Researcher).filter(
        Researcher.specialization.ilike(f'%{specialization}%')
    ).all()

Параметр: 
- specialization (TEXT) - слово або фраза для пошуку

Результат: 
Список дослідників з вбудованою спеціалізацією


ЗАПИТ 2: Обладнання вартістю вище від заданої
───────────────────────────────────────────────
Формулювання: Знайти всі одиниці обладнання, що коштують більше за задану 
              суму, разом з інформацією про лабораторію.

SQL-код:
SELECT e.*, l.name FROM equipment e
JOIN laboratories l ON e.laboratory_id = l.id
WHERE e.cost > :min_cost

Python SQLAlchemy:
def query_equipment_cost_above(min_cost):
    return db.session.query(Equipment, Laboratory).join(
        Laboratory
    ).filter(Equipment.cost > min_cost).all()

Параметри:
- min_cost (FLOAT) - мінімальна вартість

Результат:
Таблиця обладнання з вартістю та назвою лабораторії


ЗАПИТ 3: Експедиції у регіоні починаючи з року
───────────────────────────────────────────────
Формулювання: Знайти всі експедиції, що проводяться у вказаному регіоні, 
              які стартували в заданому році або пізніше.

SQL-код:
SELECT e.* FROM expeditions e
WHERE e.region = :region 
  AND YEAR(e.start_date) >= :start_year

Python SQLAlchemy:
def query_expeditions_by_region_and_date(region, start_year):
    from sqlalchemy import extract
    return db.session.query(Expedition).filter(
        and_(
            Expedition.region == region,
            extract('year', Expedition.start_date) >= start_year
        )
    ).all()

Параметри:
- region (TEXT) - назва географічного регіону
- start_year (INTEGER) - початковий рік

Результат:
Список експедицій з датами та директором


ЗАПИТ 4: Контракти з бюджетом та років дії
────────────────────────────────────────────
Формулювання: Знайти контракти, бюджет яких перевищує задану суму, та які 
              закінчуються в заданому році. Показати дослідника та організацію.

SQL-код:
SELECT c.*, r.full_name, o.name FROM contracts c
JOIN researchers r ON c.researcher_id = r.id
JOIN organizations o ON c.organization_id = o.id
WHERE c.budget > :min_budget 
  AND YEAR(c.end_date) = :end_year

Python SQLAlchemy:
def query_contracts_by_budget_and_date(min_budget, end_year):
    from sqlalchemy import extract
    return db.session.query(Contract, Researcher, Organization).join(
        Researcher, Contract.researcher_id == Researcher.id
    ).join(
        Organization, Contract.organization_id == Organization.id
    ).filter(
        and_(
            Contract.budget > min_budget,
            extract('year', Contract.end_date) == end_year
        )
    ).all()

Параметри:
- min_budget (FLOAT) - мінімальний бюджет
- end_year (INTEGER) - рік закінчення контракту

Результат:
Таблиця контрактів з дослідниками та організаціями


ЗАПИТ 5: Лабораторії за кількістю співробітників
──────────────────────────────────────────────────
Формулювання: Знайти лабораторії, що мають кількість співробітників у 
              вказаному діапазоні, з інформацією про організацію.

SQL-код:
SELECT l.*, o.name FROM laboratories l
JOIN organizations o ON l.organization_id = o.id
WHERE l.num_employees BETWEEN :min AND :max

Python SQLAlchemy:
def query_laboratories_by_employee_count(min_employees, max_employees):
    return db.session.query(Laboratory, Organization).join(
        Organization
    ).filter(
        and_(
            Laboratory.num_employees >= min_employees,
            Laboratory.num_employees <= max_employees
        )
    ).all()

Параметри:
- min_employees (INTEGER) - мінімальна кількість
- max_employees (INTEGER) - максимальна кількість

Результат:
Список лабораторій із розмірами команд

ЗАПИТ 6: Дослідники з однаковою спеціалізацією
──────────────────────────────────────────────
Формулювання: Знайти ВСІХ дослідників, чия спеціалізація збігається з 
              спеціалізацією конкретного дослідника (множинне порівняння).

SQL-код:
SELECT r1.* FROM researchers r1
WHERE r1.specialization IN (
    SELECT r2.specialization FROM researchers r2 
    WHERE r2.specialization = :specialization

def query_researchers_all_expeditions():

       COUNT(r.id) as researcher_count,

Показує для кожної лабораторії:

- Сумарна вартість обладнання: SUM(Equipment.cost)
- Кількість дослідників: COUNT(Researcher.id)

SQL-код з виразом:
SELECT l.*, 
       o.name,
       COUNT(eq.id) as equipment_count,
       SUM(eq.cost) as total_equipment_cost,
       COUNT(r.id) as researcher_count

JOIN organizations o ON l.organization_id = o.id
LEFT JOIN equipment eq ON l.id = eq.laboratory_id
LEFT JOIN researchers r ON l.id = r.laboratory_id
GROUP BY l.id

SELECT r.full_name, 
       ro.name as role_name,
       c.title,
       c.start_date,
       c.end_date,
       DATEDIFF(c.end_date, c.start_date) as duration_days,
       c.budget / DATEDIFF(c.end_date, c.start_date) as budget_per_day
FROM contracts c
JOIN researchers r ON c.researcher_id = r.id
JOIN roles ro ON r.role_id = ro.id
ORDER BY r.full_name

- Країна

- Кількість експедицій: COUNT(DISTINCT Expedition.id)
- Загальний бюджет контрактів: SUM(Contract.budget)

SQL-код з виразами:
SELECT o.*, 
       d.full_name as director_name,
       COUNT(DISTINCT l.id) as lab_count,
       COUNT(DISTINCT e.id) as expedition_count,
       SUM(c.budget) as total_budget
FROM organizations o
JOIN directors d ON o.director_id = d.id
LEFT JOIN laboratories l ON o.id = l.organization_id
LEFT JOIN expeditions e ON o.director_id = e.director_id
LEFT JOIN contracts c ON o.id = c.organization_id
GROUP BY o.id
